# ЯЕда

Telegram-бот для поиска и генерации рецептов. Поиск работает по названию, ингредиентам и описанию. Избранное хранится отдельно для каждого пользователя.

## Проверить в Telegram

Откройте [@IIIFoodbot](https://t.me/IIIFoodbot) и отправьте `/start`.

1. Нажмите **Найти рецепт** и введите `омлет` или `куриное филе, лапша`.
2. Добавьте рецепт в **Избранное**, откройте список и удалите его.
3. Нажмите **Сгенерировать рецепт** и введите `рис с овощами`. Сгенерированный рецепт тоже можно добавить в избранное.

## Запустить локально

Бэкенд использует Python 3.14 и [uv](https://docs.astral.sh/uv/). Из корня репозитория:

```bash
uv sync --locked --no-dev
uv run --locked --no-dev uvicorn main:app --host 127.0.0.1 --port 8080
```

Проверка сервера — [healthcheck](http://127.0.0.1:8080/healthcheck). Интерактивная документация API — [Swagger UI](http://127.0.0.1:8080/docs). Для локальных вызовов рецептов установите `BOT_API_KEY` в окружении процесса и передавайте его в заголовке `X-API-Key`.
